Privacy policy

hum · effective 9 October 2026

hum is a personal assistant that one person, its owner, runs on their own computer for their own accounts. It is not offered to anyone else. This policy covers what hum reads, where that data goes, and how to remove it.

Data hum reads from Google

  • Gmail (scope gmail.modify): for threads in the inbox, the sender, recipients, subject, labels and Gmail's short preview snippet. hum does not download full message bodies or attachments. It adds or removes a thread's labels, for example to archive it, only when the owner approves that action or has explicitly allowed it. hum never sends, forwards or deletes email.
  • Google Calendar (scope calendar.readonly): event times, titles, locations, organizers, attendees and the owner's own response, for the days around today. hum never changes the calendar.

Where the data is kept

In a database file on the owner's computer. hum has no server, no user accounts and no analytics. Nothing is sold, used for advertising, or shared beyond the services below.

Services that receive data

  • Anthropic: hum sends selected email metadata, calendar events and tasks to Anthropic's Claude models. They decide what needs attention and draft plans for the owner to approve. These calls run through Anthropic's API under the owner's API key, and through Claude Code under the owner's own Claude account.
  • Telegram: the daily brief and approval requests, which can include email subjects and senders, go to the owner's own chat with the owner's bot.
  • ClickUp: hum reads the owner's tasks. It comments on a task or creates one only after the owner approves.

Google API Services User Data Policy

hum's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is used only to provide hum's features to its owner. It is not used for advertising, not sold, not read by anyone other than the owner, and not used to develop, improve or train generalized AI or machine learning models.

Removing access and data

The owner can revoke hum's Google access at any time at myaccount.google.com/permissions, and deletes all stored data by deleting hum's database file.

Contact

Questions go to the owner through GitHub or the support email shown on Google's consent screen.
